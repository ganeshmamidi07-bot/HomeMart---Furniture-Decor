## About the Project

HomeMart is a modern furniture and home decor e-commerce landing page built using HTML, CSS, and JavaScript. The website presents furniture collections for different rooms, filters products by category and price, and includes a simple shopping bag experience. It is a frontend-only project designed to provide a clean, responsive, and easy-to-use shopping experience.

## Features

### Features (implemented)

- Premium hero section with furniture showcase
- Room-based categories: Living Room, Bedroom, Dining, and Home Office
- Product catalog with category and price filters
- Product cards with images, material details, and prices in Indian rupees (₹)
- Shopping bag with add-to-cart, quantity increase/decrease, remove item, and subtotal calculation
- Responsive design for desktop and mobile screens
- About section highlighting quality, delivery scheduling, and easy returns
- Indian contact details and showroom information
- Clean Navy and Orange visual theme based on the HomeMart logo

### Features (not implemented / future)

- Full product detail pages with image galleries and dimensions
- Wishlist and user account management
- Checkout form with delivery slot scheduling and Indian payment options
- Persistent cart, login, and orders using `localStorage`
- Backend authentication, inventory management, and database
- Real payment gateway integration

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. No backend setup or installation is required.
